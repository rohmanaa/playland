## 🎮 5 Game Utama (Prioritas Pengembangan)

### 1. Hijaiyah Hunt
**Genre:** Platformer 3D / Eksplorasi Voxel  
**Deskripsi:** Petualangan 3D bergaya voxel; pemain menjelajahi level dan mengumpulkan token huruf hijaiyah.  
**Tujuan Belajar:** Mengenali bentuk dan nama huruf hijaiyah, lalu berlatih membedakan huruf yang mirip.  
**Flow:** Base Camp → pilih level → jelajahi area → temukan token → pelajari huruf → checkpoint berisi latihan singkat → selesaikan level → buka level berikutnya.  
**Referensi:** Super Bear Adventure, Jump Guys (CrazyGames)  
**Status:** ✅ Sudah dibuat (`games/hijaiyah/hijaiyah.html`)

---

### 2. Tajwid Rush
**Genre:** Runner 2.5D / Obstacle Course  
**Deskripsi:** Game tantangan cepat untuk mengenali hukum tajwid melalui pilihan atau gerbang jawaban di lintasan.  
**Tujuan Belajar:** Mengidentifikasi hukum tajwid dan menghubungkan contoh bacaan dengan nama hukumnya.  
**Flow:** Pilih materi → mulai lintasan → lihat potongan contoh → pilih gerbang/jawaban → dapat umpan balik → lanjut ke tantangan berikutnya → ringkasan hasil.  
**Referensi:** Jump Guys, Kategori game obstacle (CrazyGames)  
**Status:** ✅ Sudah dibuat (`games/tajwid/tajwid.html`)

---

### 3. Wudhu Quest
**Genre:** Simulasi Interaktif 3D  
**Deskripsi:** Simulasi interaktif langkah-langkah wudhu dalam lingkungan 3D yang ramah anak.  
**Tujuan Belajar:** Memahami urutan praktik wudhu dan mengenali tindakan yang benar.  
**Flow:** Pilih mode belajar → lihat demonstrasi singkat → lakukan langkah satu per satu → dapat umpan balik → selesaikan urutan → kuis ringkas.  
**Referensi:** Super Bear Adventure, Game puzzle (CrazyGames)  
**Status:** ✅ Sudah dibuat (`games/wudhu/wudhu.html`)

---

### 4. Doa Match
**Genre:** Puzzle Matching 2D  
**Deskripsi:** Puzzle mencocokkan kartu doa dengan situasi, arti, atau audio yang sesuai.  
**Tujuan Belajar:** Mengingat doa harian, memahami kapan doa digunakan, dan mengenali maknanya.  
**Flow:** Pilih tema → kartu muncul → cocokkan doa dengan situasi/arti/audio → periksa pasangan → baca penjelasan → lanjut ke ronde berikutnya.  
**Referensi:** Match Arena, Game puzzle (CrazyGames)  
**Status:** ✅ Sudah dibuat (`games/doa-puzzle/doa-puzzle.html`)

---

### 5. Rukun Quest
**Genre:** Misi & Mini-game 2D/3D Ringan  
**Deskripsi:** Game misi dan mini-game untuk mempelajari rukun Islam; setiap misi mewakili konsep yang harus dipahami melalui aktivitas.  
**Tujuan Belajar:** Mengingat lima rukun Islam dan memahami penjelasan dasarnya sesuai tingkat usia.  
**Flow:** Masuk ke peta misi → pilih tantangan → selesaikan aktivitas/pertanyaan → dapat lencana → buka misi berikutnya → rangkuman pembelajaran.  
**Referensi:** Jump Guys, Game puzzle (CrazyGames)  
**Status:** ✅ Sudah dibuat (`games/rukun-tower/rukun-tower.html`)

## 🎯 Prioritas Pengembangan Berikutnya (Sesuai Dokumen)

### Tahap 1 — MVP 2D Paling Mudah
1. **Doa Match / Doa Memory Match** — paling mudah untuk MVP 2D
2. **Kuis Empat Pilihan / Benar atau Salah** — komponen dapat dipakai ulang
3. **Arabic Word Scramble / Huruf Mana?** — fokus huruf dan kosakata

### Tahap 2 — Setelah Konten Ditinjau Pengajar
4. **Urutan Wudhu / Tajwid Match** — butuh validasi materi
5. **Runner Kebaikan 2D** — runner sederhana, cocok untuk mobile

### Tahap 3 — Pilih Berdasarkan Kebutuhan
6. Game lain sesuai materi yang dibutuhkan siswa; **jangan membuat semuanya sekaligus**

## 🛠 Prinsip Teknis Bersama

- **Single HTML file** per game (self-contained)
- **Three.js r128 CDN** hanya untuk game 3D; game 2D pakai Canvas/CSS
- **Procedural graphics** — tanpa aset eksternal (gambar, font, audio)
- **CSS Custom Properties** untuk theming
- **HUD system** konsisten di semua game
- **Modal stack** untuk overlay (start, pause, game over, settings)
- **Fixed timestep game loop** (60 FPS target)
- **localStorage** untuk save progress
- **WebAudio synthesis** untuk SFX (tidak pakai file audio)
- **Responsive** — mobile portrait/landscape & desktop
- **Aksesibilitas** — prefers-reduced-motion, safe-area insets
